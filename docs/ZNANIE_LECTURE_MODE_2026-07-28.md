# Джарви: режим лекции по обществу «Знание»

## Пользовательский сценарий

1. Пользователь говорит: «Джарви, лекция по Знанию».
2. Джарви запускает восемь готовых аудиоглав подряд.
3. Пользователь может перебить его в любой момент.
4. Текущая глава ставится на паузу с запоминанием секунды.
5. Вопрос обрабатывает LLM с тематической базой «Знание».
6. Ответ заканчивается вопросом: «Продолжить лекцию?»
7. Команда «продолжай» возвращает аудио к точному месту остановки.

Поддерживаются также «дальше», «повтори», переход к главе по теме и завершение лекции.
Wake word распознаётся в вариантах «Джарви», «Джарвис», «Жарви» и «Жарвис».
После запуска голосового контура в интерфейсе также есть резервная кнопка
«Лекция „Знание“» — она запускает тот же сценарий, если STT не расслышал фразу.

## Архитектура

- `public/jarvi-knowledge/znanie.json` — полная тематическая база, главы, названия,
  алиасы команд и пути к аудио.
- `public/audio/jarvi/znanie/*.mp3` — готовые главы. Суммарный хронометраж около
  6 минут 36 секунд.
- `components/jarvi/jarvi-engine.ts` — состояние лекции, точная пауза, автовоспроизведение,
  выбор главы, интерактив и тематический контекст.
- Во время режима «Знание» AIRSAT-контекст заменяется, а не добавляется. Поэтому
  Worker не выбрасывает первые сообщения из-за лимита истории.
- Первая глава прогревается при старте Джарви. Следующая подкачивается в фоне,
  пока звучит текущая.
- WebAudio создаётся и разблокируется до первой сетевой операции в обработчике
  стартового касания. Это обязательно для мобильных браузеров: после `await fetch`
  transient user activation может исчезнуть и готовый MP3 не заиграет.

## Бесплатная озвучка

Аудио создано локальной Silero v4, мужской голос `eugene`. Повторная генерация:

```powershell
E:\Projects\voice-bot-demo\venv\Scripts\python.exe scripts\generate-znanie-audio.py
```

Обратная проверка локальным Whisper:

```powershell
E:\Projects\voice-bot-demo\venv\Scripts\python.exe scripts\verify-znanie-audio.py
```
